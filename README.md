# iolite
Iolite est une web app mobile pour pointer ses heures de travail en restauration : services en continu ou en coupure, pauses, repas fournis, totaux par semaine, mois et année, estimation du salaire brut et net, heures sup, congés payés, alertes sur les temps de repos légaux et comparaison avec le planning Combo. Comptes sécurisés via Supabase.
